# 安装与回退

## 先备份

关闭 Obsidian。备份当前配置目录中的 `appearance.json`、现有主题和样式片段。默认配置目录是 `.obsidian`；如果设置过「切换设置文件夹」，请使用你自己的实际配置目录。

## 安装独立主题（推荐）

1. 解压主题包，找到 `Sakura Glass` 文件夹，确认里面直接有 `theme.css` 和 `manifest.json`。
2. 将整个文件夹复制到仓库的 `<配置目录>/themes/`。不要覆盖整个 `.obsidian`，不要替换你的笔记。
3. 打开 Obsidian → 设置 → 外观，在主题下拉框选择 Sakura Glass。
4. 若主题列表未出现，关闭后重新打开应用；检查是否多套了一层同名文件夹。
5. 如果旧主题片段改变了背景，临时关闭对应片段后比较效果。不要关闭负责原有导航布局的插件。

## 调节玻璃效果

可选：在 Obsidian 官方社区插件市场安装 Style Settings。打开「设置 → Style Settings → Mac 玻璃质感」调节：

- 面板磨砂强度：默认 10，范围 0–18；卡顿时降到 4–6 或 0。
- 面板不透明度：默认 78%，数值更高更易读、更低更透。
- 「Phycat 配色设置」可分别改亮暗颜色。
- 想保留自己的 Power Explorer / Iconic 图标，可在卡片布局设置关闭主题文件和文件夹图标。

独立主题已经包含玻璃效果，不要再额外启用 `phycat-glass-mac.css`，以免重复覆盖。该片段仅供继续使用原 Phycat 的进阶用户。

## 原 Phycat 的片段安装方式（进阶）

保留原 Phycat，将 `snippets/phycat-glass-mac.css` 放进配置目录的 `snippets/` 并启用，再经 Style Settings 导入 `presets/Sakura-Glass.json`。不要导入陌生人的完整插件 data.json 或 workspace.json。

## 分栏导航

本主题保留 Power Explorer 的文件夹／文件列，但不会自动创建这种导航。已有用户保留自己的设置即可；新用户如需要，可自行从官方社区插件市场安装 Power Explorer，并按其文档启用分栏。插件可能有独立功能或许可要求，不包含在本商品中。

## 回退

设置 → 外观切回原主题。片段安装用户关闭玻璃片段即可。先保存当前设置，再按文件恢复你的备份；不要用示例仓库覆盖自己的整个配置。

## 手机

这套商品主要面向 Mac。手机继续使用原主题；玻璃定制有 `is-mobile` 条件限制。单仓库多设备建议使用各自配置目录。主题不解决 iCloud 下载或正文不显示问题。
