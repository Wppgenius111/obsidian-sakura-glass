# 使用与性能

将 Markdown 文件放进仓库后，Obsidian 会按当前主题显示标题、列表、表格、代码和提示框。带插件语法的笔记仍需对应插件；PDF 和图片内容保持原样。

可以用 `> [!note] 提示`、`> [!tip] 下一步` 等标准 Callout 组织信息。示例模板使用普通 Markdown，不需要 Dataview 或主页插件。

玻璃模糊会增加图形渲染负担，透明度不等于没有内存占用。当前只对顶层面板做有限模糊，关闭部分重复标题模糊和持续装饰动画。大表格、很多窗口和复杂插件仍可能影响性能。

验证范围：用户实际 Mac 仓库中的 Phycat 0.3.7 + 同源玻璃片段已视觉检查，二级目录右侧正确列出笔记。独立分发版已在仅含三篇虚构笔记、零社区插件的干净测试仓库中打开，视觉检查樱花配色、玻璃面板、Callout 和表格；另通过文件完整性、许可证、Markdown 示例链接和 ZIP 校验。没有内存／耗电基准数据，不把示意图当实测。
