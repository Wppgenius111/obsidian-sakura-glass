# 自定义看板适配

主题只能自动美化标准 Markdown。若旧看板通过 DataviewJS 生成 `.lg-card`、`.lg-grid` 等自定义组件，需要对应的组件样式。

本包提供 `command-center-phycat.css`，将它放进实际配置目录的 snippets 并启用，即可在 Phycat / Sakura Glass 下使用原 Luma 看板组件。看板笔记需带 `cssclasses: [luma-command-center]`。它没有附带用户的真实 Command Center 正文或研究数据。

动态看板需单独安装 Dataview 并允许 JavaScript 查询；只运行你信任的看板代码。普通示例模板不需要 Dataview。每个自定义主页的插件依赖由其作者决定。
